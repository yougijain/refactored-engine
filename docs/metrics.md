# Metrics

| Metric | Formula |
| --- | --- |
| MRR | seats × price per seat × (1 − discount) |
| ARR | MRR × 12 |
| Net new MRR | new + expansion + reactivation − contraction − churned |
| NRR (TTM) | MRR today from customers active 12 months ago ÷ their MRR then |
| GRR (TTM) | Same as NRR, but each customer capped at their starting MRR |
| Logo churn (monthly) | churned customers ÷ customers at start of month |
| Quick ratio | (new + expansion + reactivation) ÷ (contraction + churned) |
| Cohort retention | active customers (or MRR) ÷ starting customers (or MRR) of the signup month |
| Seat utilization | active users ÷ licensed seats |
| 90-day churn rate | share of account-months followed by churn within 3 months |

## MRR movement types

| Type | Rule |
| --- | --- |
| New | first month with MRR |
| Reactivation | MRR returns after churning |
| Expansion | MRR went up |
| Contraction | MRR went down but not to zero |
| Churn | MRR went to zero |
| Retained | no change |

## Health score (0–100)

40% seat utilization + 25% CSAT + 25% feature adoption + 10% tenure − 15% support tickets.

| Tier | Score |
| --- | --- |
| Healthy | 70+ |
| Watch | 55–69 |
| At Risk | 40–54 |
| Critical | below 40 |
